# KnowledgeCraft Skills Repository
This repository contains reusable public OpenCode skills.
- For coding, scripts, schemas, tests, or repository changes, apply `karpathy-guidelines` as the foundation: surface material assumptions, prefer the simplest adequate solution, keep changes surgical, and verify completion.

- Keep skills generic and reusable.
- Use `.opencode/skills/<skill-id>/SKILL.md` with lowercase kebab-case IDs.
- Supporting files belong in that skill's `references/` or `scripts/` directory.
- Do not add private research, voice samples, analytics, or user-specific paths.
- Do not add AI-detector bypass instructions.
- Do not encode unstable platform folklore as permanent facts.
- Skills handling evidence-grounded material must preserve meaning, source traceability, uncertainty, and claim strength.
