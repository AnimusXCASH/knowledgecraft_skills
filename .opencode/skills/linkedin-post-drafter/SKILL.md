# LinkedIn Post Drafter
Before drafting, know the audience, one main point, allowed claims, concrete details, and prohibited inventions.

Use the structure that best fits the idea: observation→evidence→implication; problem→mechanism→action; misconception→correction→consequence; real story→lesson; finding→interpretation→application; question→reasoned answer; or concise argument. Do not force hook + three bullets + CTA.

The opening should create legitimate curiosity through specificity, tension, contrast, or a real question. Prefer concrete detail, explain why evidence matters, retain useful technical terms, and use lists only when content is list-shaped. End with a takeaway, next step, genuine question, or no CTA. List missing personal input instead of inventing it.
