# LinkedIn Calendar Planner
Obey user dates first. Spread near-similar themes apart. Avoid consecutive posts with identical reader jobs/formats unless intentional. Put prerequisites before dependent ideas and time-sensitive content early.

If no cadence is supplied, propose a sustainable range rather than a magic frequency. If no evidence supports an exact posting time, use a broad time window/TBD. Mark experiments explicitly. Do not treat unapproved drafts as final scheduled content.
